# Διαδικασία ανάπτυξης

## Ροή
1. Έλεγχος τρέχοντος `dev` και των οδηγιών.
2. Συζήτηση απαίτησης και έγκριση.
3. Εργασία στο αποκλειστικό branch του AI.
4. Τοπικές ή αυτοματοποιημένες δοκιμές, όπου είναι εφικτές.
5. Pull Request προς `dev` με αναλυτική περιγραφή.
6. Συγχώνευση μόνο από τον ιδιοκτήτη μετά από έλεγχο.

## Δοκιμές
- Unit tests για πρωτόκολλο και business logic.
- Προσομοίωση πολλών Clients χωρίς πραγματικά δεδομένα μαθητών.
- Πραγματικές δοκιμές ήχου και installer στα Windows πριν από πιλοτική χρήση.
- Καταγραφή τυχόν δοκιμών που δεν εκτελέστηκαν.

## Οργάνωση
Ο πηγαίος κώδικας προτείνεται να διαχωριστεί σε `director/`, `client/`, `shared/`, `tests/` και `scripts/`. Οι φάκελοι θα δημιουργηθούν μαζί με την πρώτη αντίστοιχη υλοποίηση.

## Προστασία δεδομένων
Μην ανεβάζεις ονόματα ή αναγνωριστικά πραγματικών μαθητών, κλειδιά, κωδικούς ή διαπιστευτήρια στο repository.
