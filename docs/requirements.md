# Λειτουργικές απαιτήσεις — αρχική καταγραφή

## Βασική λειτουργία
- Director στον υπολογιστή διεύθυνσης και Classroom Clients στους υπολογιστές αιθουσών.
- Ζωντανές ανακοινώσεις σε μία, πολλές ή όλες τις αίθουσες.
- Τοπική λειτουργία χωρίς Internet.
- Αίθουσες με μοναδικό όνομα (π.χ. `C2627-Γ1`, `C2627-PcLab`) και πολλαπλούς Clients.
- Κάθε Client εκκινεί κατά τη σύνδεση χρήστη στα Windows, λειτουργεί στο System Tray και επιτρέπει ένα instance ανά υπολογιστή. Δεν απαιτείται Windows Service.

## Ειδοποιήσεις και απαντήσεις
- Ο Director αποστέλλει ειδοποιήσεις και λαμβάνει απαντήσεις/επιβεβαιώσεις.
- Οι μη απαντήσεις διαχωρίζονται από την αποτυχία παράδοσης και δεν θεωρούνται απόδειξη ότι η ανακοίνωση δεν ακούστηκε.

## Δήλωση απουσιών
- Μόνο ο Director μπορεί να ξεκινήσει αίτημα δήλωσης απουσιών.
- Κάθε αίτημα έχει μοναδικό αναγνωριστικό και ισχύ 15 λεπτών από την αποστολή.
- Ο εκπαιδευτικός έχει 3 λεπτά για να αποδεχθεί την ειδοποίηση.
- Μετά την αποδοχή ο Server στέλνει τη λίστα μαθητών του τμήματος.
- Σε αίθουσες μόνιμου τμήματος η επιλογή είναι προκαθορισμένη. Σε αίθουσες γενικής χρήσης (π.χ. εργαστήριο) ο εκπαιδευτικός επιλέγει τμήμα.
- Ο εκπαιδευτικός σημειώνει μόνο τους απόντες και υποβάλλει τη δήλωση.
- Δεν επιτρέπεται ανεξάρτητη ανάκτηση καταλόγων μαθητών από το System Tray.
- Οι κατάλογοι μαθητών δεν αποθηκεύονται μόνιμα στον Client.

## Ανοιχτές τεχνικές αποφάσεις
- Πρωτόκολλο μετάδοσης ζωντανού ήχου.
- Τελικός τρόπος πιστοποίησης Clients και ασφαλούς εγγραφής.
- Ακριβής πολιτική πολλαπλών απαντήσεων ανά αίθουσα και διορθώσεων δηλώσεων.
