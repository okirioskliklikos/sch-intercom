# Αρχιτεκτονική — αρχικό πλαίσιο

## Συστατικά
1. Director: διεπαφή διαχείρισης, Server, έλεγχος ανακοινώσεων και αιτημάτων.
2. Classroom Client: λήψη ήχου, εμφάνιση ειδοποιήσεων, αποστολή απαντήσεων.
3. Shared: κοινά μοντέλα δεδομένων, μηνύματα πρωτοκόλλου και επικύρωση.

## Προτεινόμενη τεχνολογία
Python και PySide6, με βιβλιοθήκες ήχου/δικτύου που θα επιλεγούν μετά από μικρό πρωτότυπο.

## Αρχές
- Ο χειρισμός ήχου να παραμένει ανεξάρτητος από το GUI.
- Κεντρικός έλεγχος έγκυρων αιτημάτων και εξουσιοδοτημένης πρόσβασης σε μαθητές.
- Καμία πραγματική λίστα μαθητών στο repository ή στα αυτοματοποιημένα tests.
- Ο Director κρατά χωριστές οντότητες αίθουσας, Client, τμήματος και μαθητή.

Το αρχείο είναι πλαίσιο, όχι οριστική απόφαση για εσωτερικά modules ή transport.
